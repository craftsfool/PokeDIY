# pokeemerald UI asset sources

These assets are copied from [`pret/pokeemerald`](https://github.com/pret/pokeemerald):

- `text-window-blue.png` — `graphics/text_window/4.png`
- `text-window-green.png` — `graphics/text_window/8.png`
- `bg-dots.png` — `graphics/pokenav/bg_dots.png`
- `bg-polkadot.png` — `graphics/pokemon_storage/wallpapers/polkadot/bg.png`
- `pokedex-arrows.png` — `graphics/pokedex/arrows.png`

They are used to reproduce the visual language of the GBA-era Pokédex UI. See the upstream repository for source and licensing details.
