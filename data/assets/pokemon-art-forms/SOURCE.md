# Regional-form official artwork

The WebP files in this directory are generated from the matching regional-form official artwork in [`PokeAPI/sprites`](https://github.com/PokeAPI/sprites). File names use the form slugs from `data/national/national-pokedex.json`.

Run `python3 PokeDIY/scripts/build-national-dex.py --form-artwork-only` to rebuild both official and pixel regional-form artwork directories.
