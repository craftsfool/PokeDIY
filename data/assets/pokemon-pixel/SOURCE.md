# Pokémon pixel sprite source

The numbered PNG files in this directory are the front-facing `default` sprites from [`PokeAPI/sprites`](https://github.com/PokeAPI/sprites), downloaded by `PokeDIY/scripts/build-national-dex.py --with-pixel-artwork`.
